SlangSense – Gen-Z Slang Detection & Emerging Trend Analysis

SlangSense is a data-driven application developed using Python, Natural Language Processing (NLP), and Machine Learning to identify Gen-Z slang, analyse slang usage patterns, discover topics in social media conversations, and explore engagement trends.

Features

Slang Detection: Identifies recognised Gen-Z slang terms, displays their meanings, and predicts text categories using Machine Learning.

Slang Frequency Analysis: Analyses tweet data to identify frequently used slang expressions.

Topic Analysis: Discovers groups of related social media discussions using Sentence-BERT embeddings and K-Means clustering.

Engagement Analysis: Examines social media engagement metrics, including views, likes, shares, and comments.

Technologies Used

Programming: Python

Data Analysis: Pandas, NumPy

Natural Language Processing: NLTK, TF-IDF

Machine Learning: Scikit-learn, Linear SVM

Topic Discovery: Sentence-BERT, K-Means

Visualization: Matplotlib

Web Application: Streamlit

Machine Learning

The project uses a TF-IDF Vectorizer and Linear Support Vector Machine (SVM) for text category classification.

Model Accuracy: 95.45%

Note: The classification results are affected by the imbalance in the training dataset.
